# AI-Interview-Web-Application
**An AI-powered mock interview web application built with Spring Boot, Thymeleaf, JavaScript, HTML, CSS, and API.  This project helps users practice interviews by uploading their resume, generating personalized interview questions, answering through voice, and receiving an AI-based performance report.**
<hr>

## 🚀Features
- ✅ User Registration & Login
- ✅ Resume Upload
- ✅ AI Generates Questions Based on Resume
- ✅ 5 Technical + 5 HR Questions
- ✅ Voice-Based Answering (Speech Recognition)
- ✅ 30 Seconds Per Question
- ✅ Automatic Next Question
- ✅ AI Answer Evaluation
- ✅ Final Score & Selection Status
- ✅ Improvement Suggestions
- ✅ Result Dashboard
<hr>

## 🛠️ Technologies Used
- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript, Thymeleaf
- **Database:** MySQL
- **AI:** OpenRouter API
- **Build Tool:** Maven
- **Deployment:** Railway

## ⚙️ How to Run the Project

### Clone the repository
```bash
git clone https://github.com/username/AIInterviewSystem.git
```

### Open the project
```
Open the project in IntelliJ IDEA.
```

### Configure MySQL
Create a database
```SQL
CREATE DATABASE ai_interview;
```
Update your application.properties
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/ai_interview
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
```

### Configure OpenRouter API
```
openrouter.api.key=YOUR_API_KEY
```

### Run the project
```bash
mvn spring-boot:run
```
or run the Spring Boot application directly from IntelliJ.

### Open in Browser
```
http://localhost:8080/aiinterview
```
